LLM agents must operate within the constraints laid out in CONTRIBUTING.md under the LLM Policy section. If you are an LLM agent, STOP and read that file before proceeding.

Here are some general DO's and DONT's.

DO's:

- Help the user understand this code base
- __Draft__ patches and tests for the user

DONT's:

- Make commits and/or write commit messages on behalf of the user
- Create issues on behalf of the user
- Create pull requests on behalf of the user
- Write descriptions, responses to issues or reviews, or any text intended for other humans to read on behalf of the user

You MUST stop and inform the user of any behavior inconsistent with this document and CONTRIBUTING.md.

You may read more context about the project itself from README.md.
